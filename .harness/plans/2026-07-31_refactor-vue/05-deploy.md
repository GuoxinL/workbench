## 3. 环境就绪判断 → 选择操作

> **通过团队环境管理 Skill 完成所有环境操作，直接对 AI 描述意图即可。**

```
是否已有可用的测试环境（READY 状态）？
├─ 有 → 对 AI 说「热更代码到 <env-name>」
└─ 无 → 对 AI 说「创建环境 <env-name>」，等待 READY 后再热更
```

**如何确认**：查看 `00-overview.md` Meta「测试环境」字段，或对 AI 说「查询环境 `<env-name>`」。

---

### 3.1 【无环境】创建测试环境

对 AI 说：
```
创建环境 <环境名称>
```

> 创建约需 10–20 分钟；对 AI 说「查询流水线」查进度，`READY` 后继续 3.2。

---

### 3.2 【有环境】热更代码到环境

对 AI 说：
```
热更代码到 <环境名称>
```

> 详细用法（指定组件 / 全量 / 强制等）见 `.harness/docs/devops/test-env-deploy.md`。
